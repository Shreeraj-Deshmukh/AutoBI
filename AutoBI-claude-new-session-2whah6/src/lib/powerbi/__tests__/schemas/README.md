Microsoft's published JSON schemas for Power BI Project (PBIP / PBIR) files, used by
`powerbi.test.ts` to validate the export. Copied unchanged from
https://github.com/microsoft/json-schemas (MIT licence); the folder layout mirrors
`https://developer.microsoft.com/json-schemas/<path>` so relative `$ref`s resolve.

The versions here are the ones the export writes (see `SCHEMA` in `../../report.ts`).
